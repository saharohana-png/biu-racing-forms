# פרסום האתר בחינם

[חזרה להתחלה](../README.md)

הקוד נשמר ב־GitHub. האתר רץ ב־Vercel במסלול Hobby, והנתונים והקבצים נשמרים ב־Supabase במסלול Free. התרגום רץ בדפדפן המשתמש. אין שימוש ב־AI Gateway ואין מפתח API בתשלום.

**האתר הפעיל:** https://biu-racing-forms.vercel.app

**ניהול האחסון:** [הפרויקט בחשבון הבעלים](https://vercel.com/saharohana-6274s-projects/biu-racing-forms). האתר כבר שויך לחשבון ואינו פריסה זמנית. חמשת משתני השרת שמורים כסודות בסביבת Production.

## מפרסמים שינוי שנשמר ב־Git

כרגע הפרסום ידני; בדיקות GitHub פועלות אוטומטית, אך מיזוג ל־main אינו משנה מיד את האתר הציבורי.

1. שותף עם הרשאת כתיבה שומר את השינוי ב־main, ישירות או באמצעות מיזוג שהוא מבצע בעצמו. אין דרישה לאישור הבעלים; בודקים שהבדיקות עברו לפני הפרסום.
2. מורידים את המקור העדכני דרך Code → Download ZIP ומחלצים את התיקייה שמכילה את `package.json`.
3. פותחים את פרויקט Vercel הקיים בקישור למעלה ומעלים אליו את תיקיית המקור דרך אפשרות בחירת התיקייה או גרירה לעמוד הפרויקט. הקובץ `vercel.json` מגדיר את ההתקנה והבנייה.
4. מחכים למצב Ready, פותחים את הכתובת הפעילה ובודקים כניסה, הצגת נתונים וייצוא. הנתונים נשארים ב־Supabase גם כשהקוד מתחלף.

אין לפתוח פרויקט חדש לכל שינוי ואין להעלות קובצי `.env`, גיבויים או תשובות צוות. הרשאות עבודה על הקוד ניתנות דרך GitHub; שימוש באתר אינו דורש חשבון Vercel לחברי הצוות. אפשר לחבר בעתיד GitHub ישירות ל־Vercel דרך Settings → Git כדי לפרסם בעקבות מיזוג.

## משתני הסביבה של השרת

מגדירים ב־Vercel, בפרויקט האתר, תחת Settings → Environment Variables. הערכים הסודיים אינם נכנסים למאגר.

| שם | משמעות |
| --- | --- |
| FORMS_GATEWAY_URL | כתובת פונקציית האחסון ב־Supabase |
| FORMS_GATEWAY_KEY | מפתח שרת אקראי; רק הגיבוב שלו נשמר במסד |
| FORMS_OWNER_KEY | מפתח הכניסה האישי לרכז |
| FORMS_SESSION_KEY | מפתח חתימה לעוגיות ולכרטיסי העלאה |
| FORMS_TEAM_CODE | קוד צוות שמוסרים רק למי שמורשה לעבוד על הטפסים |

הכניסה לרכז נמצאת בנתיב `/admin-login`. כניסת הצוות דורשת קוד צוות ומייל אוניברסיטאי; המייל הוא הצהרה עצמית ואינו מעניק הרשאת רכז. קוד הצוות מחליף את שער Cloudflare Access שהיה בתצורה הקודמת. סבב מפתח החתימה מבטל עוגיות מנהל קיימות; ביטול חבר צוות נעשה דרך מסך הניהול.

## מסד וקבצים

מבנה PostgreSQL נמצא בתיקיית `supabase/migrations`. פונקציית `forms-gateway` בודקת מפתח שרת לפני כל פעולה. הטבלאות נמצאות בסכמה פרטית עם RLS חסום למשתמשי דפדפן. פונקציות המסד ניתנות להפעלה רק בידי תפקיד השרת. אין מפתח שירות בקוד הדפדפן.

קבצים גדולים עולים ישירות לאחסון הפרטי בכתובת חתומה לקובץ יחיד, ואז עוברים אימות בשרת. הנתונים המקוריים אינם נשמרים ב־Git. אין משימת רקע שסורקת Discord או Drive.

## בנייה ופרסום

הקובץ `vercel.json` מגדיר בניית Next.js. השירות מוריד את תבניות המקור הרשמיות ובודק SHA-256 בזמן הבנייה. שותפים יכולים לשמור קוד ישירות ל־main; הבדיקות רצות אחרי ההעלאה. פרסום אוטומטי תלוי בחיבור מאגר GitHub לפרויקט Vercel. הרשאת כתיבה ב־GitHub אינה מוסיפה גישה לחשבון Vercel.

## גבולות המסלול החינמי

אין שירות אחסון חיצוני בעל משאבים אינסופיים. אין לשדרג ל־Pro או להפעיל שירות מחויב לפי שימוש בלי החלטה מפורשת של הבעלים. ב־Free של Supabase קיימים 500 MB למסד, 1 GB לקבצים, ומגבלות תעבורה; פרויקט עשוי להיעצר לאחר שבוע ללא פעילות. התרגום המקומי אינו צורך מכסת ChatGPT או Lovable. [Supabase Free](https://supabase.com/pricing) · [Vercel Hobby](https://vercel.com/docs/plans/hobby).

תצורות Cloudflare הישנות נשמרו לצורך שחזור היסטורי בלבד. אין להפעיל R2 או להשתמש בפקודות הפרסום הישנות לצורך הפריסה הזאת.
