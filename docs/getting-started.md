# התקנה והפעלה במחשב

[חזרה לעמוד הראשי](../README.md) · [מדריך העריכה](editing-guide.md)

המדריך מפעיל עותק מקומי לפיתוח, עם מסד מקומי וזהות רכז לפיתוח. תשובות ומשתמשים מהשרת הפעיל אינם מועתקים אליו.

## 1. כלים נדרשים

התקינו Git ו־Node.js בגרסת 22.13 ומעלה. הבדיקות האוטומטיות משתמשות ב־Node 22; זו הגרסה המומלצת לעבודה אחידה. npm מותקן יחד עם Node.js. נדרש חיבור ראשוני לאינטרנט להורדת החבילות, התבניות ומודל התרגום.

פתחו מסוף והורידו את המאגר. אם אתם מציעים שינוי בלי הרשאת כתיבה, שכפלו במקום זאת את כתובת ה־Fork שלכם מכפתור Code ב־GitHub.

</div>

```sh
git clone https://github.com/saharohana-png/biu-racing-forms.git
cd biu-racing-forms
```

<div dir="rtl">

## 2. הכנה ראשונית

הריצו מתוך תיקיית הפרויקט, לפי הסדר:

</div>

```sh
npm ci
npm run templates:prepare
npm run setup:local
npm run dev
```

<div dir="rtl">

| פקודה | מה היא עושה? |
| --- | --- |
| `npm ci` | מתקינה את הגרסאות המדויקות מתוך קובץ הנעילה |
| `npm run templates:prepare` | מורידה תבניות רשמיות ומוודאת שהן זהות לקבצים שמופו בקוד |
| `npm run setup:local` | מכינה את המסד המקומי ואת רכז הפיתוח |
| `npm run dev` | בונה את מנוע התרגום ומפעילה שרת פיתוח |

פתחו **http://127.0.0.1:5173**. זו כתובת שרצה רק במחשב שלכם. השאירו את המסוף פתוח; לעצירה לחצו Ctrl+C. בהפעלות הבאות מספיק בדרך כלל להריץ `npm run dev`. אחרי הוספת מיגרציה יש להריץ שוב `npm run setup:local`.

אין צורך במפתח API לתרגום. ההפעלה הראשונה מורידה כ־365 MB של משקלי מודל וקובצי הרצה נוספים. סגירת העמוד עוצרת את התרגום; פתיחת הטופס שוב ממשיכה עבודה ממתינה.

## 3. בדיקה לפני הגשת שינוי

</div>

```sh
npm run check
npm run catalog:check
npm run build
```

<div dir="rtl">

הפקודה הראשונה בודקת טיפוסים ומריצה את הבדיקות. השנייה בודקת שמפת המערכות תואמת לקטלוג. השלישית בונה את האתר לפרסום, אך **אינה מפרסמת אותו**. בדקו גם את הפעולה ששיניתם בדפדפן.

## תקלות נפוצות

| מה קרה? | מה לבדוק? |
| --- | --- |
| פקודת npm לא נמצאה | התקנת Node.js ופתיחה מחדש של המסוף |
| חסרה תבנית או הכנתה נכשלה | הריצו `npm run templates:prepare`; כישלון בדיקת החתימה דורש בדיקת גרסה ומיפוי |
| מסד מקומי חסר או חסרה טבלה | הריצו `npm run setup:local` מתיקיית הפרויקט |
| מפת המערכות אינה מעודכנת | הריצו `npm run catalog:generate` אחרי עריכת הקטלוג ובדקו את ההפרש |
| התרגום ממתין או נכשל | בדקו את הודעת המצב, האינטרנט והורדת המודל; נסו שוב דרך הכפתור באתר |

הקמה לשרת אמיתי מפורטת ב[מדריך הפרסום](deployment.md). אין להפעיל מצב פיתוח `LOCAL_DEV` בשרת ציבורי.
